Some of my projects

  • Memory Game MANIA

    A full-stack, responsive memory matching game built with Vanilla JavaScript, Node.js and CSS3. Features include dynamic CSS Grid layouts, custom API data fetching. Architected a RESTful API with Knex.js and SQLite to serve categorized card decks and game configurations.

  • Currency Converter

    Fun project focused on working with external APIs and dynamic DOM updates. The app calculates exchange rates as users type, swaps currencies with a click, and asynchronously loads national flags to match user's selection.

  • Sorting Hat

    This project was part of the HackYourFuture program assignment for introduction to frontend class. It is still in its beginning, and it is made entirely using HTML, CSS and vanilla JS

  • The Hangman Game

    A cinema-themed twist on the classic Hangman game, built as a collaborative project. Developed using React, the application integrates an external movie API to dynamically fetch film titles for users to guess, utilizing React's state management to handle the gameplay mechanics.

  • FlashCards

    A collaborative study tool built entirely with Vanilla JavaScript, HTML, and CSS. The application allows users to create custom flashcard decks, download their study sets, and features an interactive two-player game mode to competitively test knowledge retention.

  • EvenTeam - Tech Event Ticketing Platform

    A fully responsive single-page application built with React for discovering and purchasing tech event tickets. The platform features user authentication, a complete shopping cart and checkout flow, order history tracking, and dynamic event search and filtering, all supported by a JSON Server REST API backend.
